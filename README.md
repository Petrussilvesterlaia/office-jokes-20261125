This Python program writes a single one-line joke about office life to `/output/entry.txt`. It was built as an entry for the make.fun One-Line Office Jokes bounty. Running it takes only a second and produces a short, self-contained joke file ready for submission.

## How to run

```bash
python3 main.py
```

Then check the result at `/output/entry.txt`.
